# Websphere 9.0.5.21 Installation

### go to the PATH
```
cd /apps/IBM/InstallationManager/eclipse/tools
```
## Install WAS 9.0.5.21
```
./imcl install \
com.ibm.websphere.ND.v90_9.0.0.20160526_1854 \
com.ibm.java.jdk.v8_8.0.3000.20160526_1317 \
-repositories https://www.ibm.com/software/repositorymanager/com.ibm.websphere.ND.v90 \
-installationDirectory /apps/IBM/WebSphere/AppServer \
-sharedResourcesDirectory /apps/IBM/IMShared \
-acceptLicense \
-showProgress \
-log /var/log/IBM/was/WAS_ND_install_$(date +%Y%m%d_%H%M%S).log \
-prompt
```
